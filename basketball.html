How We Train

Learn It. Rep It. Use It.

Anybody can look good when it goes exactly as planned.
Build the skill. Speed it up. Add pressure. Make the next read.
Because nobody's guarding you in the drill.

01 — Handle

Control. Footwork. Pace.

Keep the ball. Change speeds. Change direction.

Get them leaning. Go the other way.

02 — Shoot

Mechanics. Balance. Reps.

Build a shot you trust.

Wide open is the easy part.

03 — Read

See It. Decide. Go.

See the space. See the help. See the next play.

The right move beats the fancy one.

04 — Compete

Pressure. Confidence. Play.

Take the shot. Make the pass. Guard your person. Get back.

Enough rehearsing. Let's play basketball.

Because Eventually,Somebody Has to
Take the Shot.

Start Here. Keep Going.

The Work Changes as They Do.

Ages 6–9

Build the Base.

Ball control. Footwork. Shooting.
Lots of touches.

Learn the game. Love it.
Ask for one more shot.

Ages 10–13

Add Speed. Add Decisions.

Stronger fundamentals. Faster reads.
More competition.

Less thinking. More playing.

Ages 14+

Make It Game Ready.

Sharper reps. Smarter decisions. More pressure.

The little stuff is the big stuff now.
