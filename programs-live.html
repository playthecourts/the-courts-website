Preview — not linked from the site

Every card below is rendered live from Courts OS. Publishing a camp or an event there makes it appear here; archiving it makes it disappear. No HTML edit, no deploy.

To use this on a real page, add <script src="js/courts-programs.js" defer></script> and drop an empty <div data-courts-programs></div> wherever the cards belong. Filter with data-sport, data-type and data-limit.

Opened from localhost it reads a local Courts OS on port 3000; anywhere else it reads admin.playthecourts.com.
