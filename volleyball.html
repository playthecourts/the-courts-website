How We Train

Learn It. Rep It. Use It.

Anybody can pass when the ball comes right to them.
Build the technique. Speed it up. Add pressure. Learn to adjust.
Because nobody's serving you the perfect ball in a match.

01 — Pass

Platform. Feet. Control.

Build the platform. Move your feet. Control the ball before it controls the point.

Make the next touch easier, not more interesting.

02 — Set

Hands. Feet. Target.

Get to the ball. Square up. Put your hitter somewhere they can do something with it.

A little less "good luck." A little more "go get it."

03 — Attack

Approach. Timing. Finish.

Learn how to hit with purpose instead of just hitting hard.

No half-sends.

04 — Compete

Read. Talk. Adjust.

Read what's happening. Communicate. Adjust. Then go get the next ball.

If it hasn't hit the floor, we're still playing.

Because Eventually,It Has to Work
in a Match.

Start Here. Keep Going.

The Work Changes as They Do.

Ages 6–9

Build the Base.

Ball control. Footwork. Learning to track the ball off a serve. Lots of touches.

Learn the game. Love playing it. Ask for one more rally.

Ages 10–13

Add Speed. Add Decisions.

Cleaner technique. Faster footwork. Real positional roles start to matter.

Less thinking about the touch. More knowing where to put it.

Ages 14+

Make It Game Ready.

Sharper reps. Smarter reads. More pressure. More purpose.

The small habits are the whole game now.
